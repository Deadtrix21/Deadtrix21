# Profile artwork

The personal profile uses the same dark technical field-note palette as Noxius Studium: charcoal, warm ivory, teal signal paths, and sparse amber detail.

## Original personal-profile assets

- `hero.svg` — Deadtrix21 identity and question/build/measure/refine signal.
- `focus.svg` — systems, contracts, and interfaces.
- `znrg-research.svg` — public artifact inventory, not a security evaluation or benchmark.
- `toolset.svg` — tools grouped by purpose, with exploration distinguished from experience.
- `working-loop.svg` — personal working process.
- `selected-work.svg` — compact alternative project overview, retained but not embedded in the expanded profile.

## Shared Noxius artwork

`fluid-music.svg`, `enchanted-composer.svg`, and `event-systems.svg` are reused at the profile owner's request from [Noxius Studium's profile assets](https://github.com/noxius-studium/.github/tree/main/profile/assets). They explain the same public projects in both profiles.

All embedded assets are self-contained SVGs with accessible titles/descriptions and a reduced-motion fallback. The diagrams are explanatory illustrations, not application screenshots, measured performance results, or third-party certifications. No remote fonts or scripts are required.

The earlier fantasy/dragon explorations are not part of the published profile.
